## 标题

标题有两种表示法
1. 一种是将`=` 放在标题下方构成一级标题,将`-` 放在标题下方构成二级标题
2. 另一种表示法是用`#` 放在行首,后边加上标题,通过控制`#` 的个数来实现多级标题.

这里需要 **注意** :
1. `#` 必须放在行首,前边不能有空格
2. `#` 与标题之间必须有一个空格
3. 一级标题只能有一个
4. 尽量避免跨层次使用标题,即一级标题下应该是二级标题,最好不要在一级标题下放三级标题

下一个就是标题编号,有两种实现方式
1. 第一种是解析器自动实现的编号,用户只需要放标题就可以了,显然obsidian的解析器默认不是这样的
2. 第二种是手动编号,在`#` 后,标题前加上数字,这需要我们自己去手动处理,效率比较低

最后就是标题锚点
标题在写出来之后,解析器就会自动为其创建对应的锚点,锚点的用处就是可以快速定位到对应标题的地方,可以快速查找内容.

## 文本格式

段落换行和另起一段
1. 段落换行是因为一段太长了,为了可读性必须换一行,这里有三种方法
    - 直接回车另起一行,注意不要按两下形成空行
    - 使用`<br>`  标签进行换行
    - 使用`\` 进行换行,但是有的解析器不识别(显然obsidian不这样处理)
2. 另起一行是通过回车形成空行来实现的,另起一行也通常用来隔离不同元素

对字体进行处理
1. 加粗:使用`**内容**`来**加粗内容**
2. 斜体:使用`*内容*`来使*内容倾斜*
3. 粗斜体: 使用`***内容***` 使内容变成***粗斜体***
4. 删除线:使用`~~内容~~` 来给内容加上~~删除线~~ .
5. 下划线:使用`<u> 内容 </u> `来给内容加上<u>下划线</u>
6. 脚注: 使用`[^脚注名]`来添加脚注,脚注[^这是一个脚注]
   还需要实现脚注的内容
7. 行内代码标记:使用\`内容\` 来对内容增加`行内代码标记` 
8. 多行代码标记:使用\''' 内容 \''' 来对多行内容进行标记
   ```cpp
   #include<iostream>
   using namespace std;
   int main()
   {
	   cout<<"hello world"<<endl;
	   return 0;
   }
   ```
9. 文本高亮:
   -  第一种方法是`==内容==` 进行 ==高亮==
   - 第二种方法是`<mark> 内容 </mark>` 进行<mark>高亮</mark>

[^这是一个脚注]: 脚注测试

## 链接

- 这里的链接指的是网址链接（**URL**），可以在url后边加上`"字符串"` ,鼠标悬停在上方时,就会显示对应的提示,这个叫做**链接标题** 。
- 参考链接：类似于一个字符替换。当多个不同位置的链接指向同一个网址时，可以集中管理网址，如果网址改变，只需要修改一个网址即可实现全部修改。参考链接一般放在文末，因为我们不点他，渲染之后在文档中和普通超链接是一样的。并且这种方式也是可以加链接标题的。
- 直接在markdown文件中输入URL或者邮箱地址也是可以自动变成链接的， 就是没有别名罢了
-  前边的**标题锚点** 也算是一种链接
  1. 自定义锚点:`^+"字符"` 的形式去放置一个锚点,等待需要跳转的时候直接`[](#)` 在井号后边加上这个自定义锚点就可以了
  2. 返回顶部的链接就可以用自定义锚点的方式实现,发现这个obsidian中的大标题并不是`# 标题` 所以不能直接跳转这个大标题.

## 图片

图片和链接的语法类似,只是在前边加上一个`!` ,`()` 中放的是图片的绝对路径/相对路径/**网络URL** ,注意URL可以直接用在这里

- 和链接类似,图片链接也可以用 **图片链接标题** 
- 也可以用参考链接的方式写这个,但**注意** 这时候的语法和**链接** 是一样的,没有`!` .
- 图片语法`[]` 中的内容是图片内容失效时展示给用户的内容.
- `[![图片描述](图片路径)](URL)`  通过这种形式将链接嵌入到图片中，点击图片就能跳转链接

## 表格

obsidian中的表格书写格式很简单,将表头和分割线打出来就会自动生成表格了
**注意** : 如果一个表项太长或者在某一个表项中需要划分很多点,我们就需要用`<br>` 来进行换行
表格中的元素布局也是可以设置的.
``` 语法格式
|表头1|表头2|
```
1. `|:-----|`  表示左对齐
2. `|-----:|`  表示右对齐
3. `|:----:|`  表示居中对齐

## 数学公式

这里不对数学公式的编写提出过多的要求,理解大概怎么写的就可以,如果以后用的多可以再学习,现在用得少,不管怎么学,到后边都会忘光光,所以现在就不费那么多力去钻研这个了.

markdown中的公式编辑实际上是借鉴了**Latex** 的语法
基础的结构
1. 行内公式
2. 块级公式
3. 基础命令
	- 命令，所有的命令都是以`\` 开头的,用命令来给出我们键盘没有的数学符号,
	- 参数,用 `{ }` 来包围数学公式中使用的参数
	- 下标,用 `x_2` 这种形式来写 $x_2 = 4$ .
	  **注意** `$`与公式直接相连
	- 上标,用`x^2` 的形式来写$x^2  = 4$ 
	- 分组,用`{}` 来包括多个字符组合

具体语法查看[Markdown 数学公式 | 菜鸟教程](https://www.runoob.com/markdown/md-math.html)
